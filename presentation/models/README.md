# 3D-модели для презентации

Сюда нужно положить 3D-модель робота AK-2000 для слайда «Кастомные модели роботов в 3D».

## Поддерживаемые форматы (порядок приоритета)

1. **GLB (рекомендуется)** — единый бинарный файл, всё внутри (геометрия + материалы + текстуры).
   - Имя файла: `ak-2000.glb`
2. **OBJ + MTL** — пара файлов, текстуры (если есть) рядом.
   - Имена: `ak-2000.obj` и `ak-2000.mtl`

Вьювер сначала ищет `.glb`. Если его нет — пробует `.obj` (с материалами из `.mtl`,
если файл присутствует). Если ни одного нет — на слайде покажется аккуратный плейсхолдер.

## Как открыть

После того как файл положен в эту папку, поднимите локальный сервер
(чтобы браузер мог `fetch` файл — `file://` для модулей не работает):

```bash
cd presentation
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Управление вьювером

- Перетаскивание мышью — вращение вокруг модели
- Колесо — зум
- При первом взаимодействии автоповорот выключается

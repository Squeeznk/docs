# Automacon WCS — Презентация (итоги квартала)

Презентация на 5 минут об **итогах квартала по продукту Automacon WCS**
для коллег из смежных подразделений.

Фокус — на 7 значимых достижениях квартала, а не на самом продукте.

## Как запустить

Презентация — самодостаточный HTML-файл на [reveal.js](https://revealjs.com/)
и подгружает все зависимости с CDN.

- Открыть локально: дважды кликнуть `index.html` (или перетащить в браузер).
- Через локальный сервер (рекомендуется):

  ```bash
  cd presentation
  python3 -m http.server 8000
  # открыть http://localhost:8000
  ```

## Навигация

- `→` / `Space` — следующий слайд
- `←` — предыдущий
- `Esc` — обзор всех слайдов
- `F` — полноэкранный режим
- `S` — заметки докладчика

## Структура (14 слайдов, ~5 минут)

1. Титульный слайд
2. Квартал в одном слайде — все 7 достижений
3. Достижение 01 — Полевой пилот ВкусВилл «Вешки» (AK-2000 + Modbus-симулятор)
4. Достижение 02 — Нагрузочные тесты на 1000 устройств
5. Достижение 03 — Релиз телеметрии «машины времени»
6. Достижение 04 — Быстрая разработка кастомных блоков воркфлоу
7. Достижение 05 — Кастомные 3D-модели роботов
8. Достижение 06 — Собственный редактор карт LIF
9. Достижение 07 — Multi-agent AI ассистент (обзор)

# Картинки для презентации

## `lif-editor.png` — скриншот редактора карт LIF

Используется на **слайде 8 «Собственный редактор карт»** (PR-презентация по итогам квартала).

### Что положить

Положите скриншот редактора карт в формате PNG (или JPG, тогда поправьте путь
в `index.html`) под именем:

```
presentation/images/lif-editor.png
```

Рекомендуется ширина **≥ 1400 px**, без альфа-канала. Можно класть полный
скриншот окна редактора целиком — на слайде он будет аккуратно стилизован под
общую тёмно-зелёную палитру презентации.

### Что делается со скриншотом автоматически

К изображению применяется CSS-фильтр для приведения цветов в общий
зелёный duotone-стиль презентации:

- `contrast(1.05)` + `saturate(0.55)` — приглушаются яркие цвета UI редактора
- `hue-rotate(105deg)` — синие/красные акценты сдвигаются в зелёный диапазон
- `brightness(0.92)` + `sepia(0.18)` — затемнение и лёгкая тонировка

Поверх накладываются:

- Зелёный градиентный «wash» (`mix-blend-mode: screen`)
- Виньетка по краям (`mix-blend-mode: multiply`)
- Тонкие сканлайны для «диспетчерского» ощущения
- HUD-бейдж `LIF · v3` сверху-справа и подпись `OWN MAP EDITOR · LIF` снизу

Если файла нет — на слайде покажется аккуратный плейсхолдер с подсказкой,
куда его положить.

### Запуск

Откройте презентацию через локальный сервер (нужен из-за `fetch` для 3D-модели):

```bash
cd presentation
python3 -m http.server 8000
# открыть http://localhost:8000
```

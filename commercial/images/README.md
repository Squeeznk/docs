# Скриншоты для краткого коммерческого описания

В кратком документе `commercial/automacon-wcs-shortform.md` используются 5 скриншотов
интерфейсов платформы. Положите файлы под этими именами в текущую папку:

| № | Файл | Что должно быть на скриншоте |
|---|---|---|
| 1 | `screen-01-map-fleet-table.png` | Карта склада + поверх неё таблица роботов с показателями (заряд, позиция, режим, статусы движения и активности) |
| 2 | `screen-02-ai-assistant.png` | Карта склада + окно AI-ассистента с диалогом (например, «Кто сейчас на зарядке?» и «Сколько миссий выполнено за последние 6 часов?») |
| 3 | `screen-03-workflow-constructor.png` | Конструктор шаблонов миссий с собранным процессом и палитрой действий справа |
| 4 | `screen-04-fleet-cards.png` | Карточный обзор парка роботов с актуальными статусами (`IDLE`, `DRIVING`, `CHARGING`, `ERROR_CRITICAL`, `OFFLINE`) |
| 5 | `screen-05-lif-editor.png` | Редактор карт LIF: холст с узлами/рёбрами/станциями + панель свойств ребра |

Рекомендации:

- Формат — **PNG** (чёткая отрисовка интерфейса).
- Минимальная ширина оригинала — **1400 px** (хорошее качество в печатной версии).
- Без альфа-канала и водяных знаков.
- Перед публикацией скрыть конфиденциальные данные конкретных заказчиков
  (имена пользователей, реальные ID объектов, адреса электронной почты) — например,
  через размытие или замену в любом редакторе.

После добавления файлов скриншоты появятся в документе при открытии его
в любом средстве просмотра Markdown (GitHub, VS Code, Typora) и при экспорте
в PDF/DOCX через Pandoc.

## Унификация внешнего вида (опционально)

Если хочется, чтобы все 5 скриншотов выглядели согласованно (одинаковая ширина,
лёгкая обработка для печати), запустите скрипт `prepare.sh` рядом с этой папкой.
Скрипт ничего не удаляет — он создаёт оптимизированные копии в подпапке `processed/`,
которые потом можно подменить в основной папке вручную.

```bash
cd commercial/images
./prepare.sh
```

Скрипт требует установленного `ImageMagick` (`convert` / `magick`):

```bash
sudo apt-get install imagemagick   # Debian/Ubuntu
brew install imagemagick           # macOS
```

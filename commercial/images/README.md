# Скриншоты для краткого коммерческого описания

В кратком документе `commercial/automacon-wcs-shortform.md` используются 4 скриншота
интерфейсов платформы. Положите файлы под этими именами в текущую папку:

| Файл | Что должно быть на скриншоте |
|---|---|
| `screen-01-map.png` | Карта склада в реальном времени с парком роботов, точками, дорогами и периферией. Желательно режим 2D или 3D с активными объектами. |
| `screen-02-ai-assistant.png` | Окно AI-ассистента с примером диалога на естественном языке (например, «Что делал AGV-003 примерно 20 минут назад?» с подробным ответом и упоминанием вызванного навыка). |
| `screen-03-lif-editor.png` | Редактор карт LIF: холст с узлами/рёбрами/станциями и боковая панель свойств выбранного объекта. |
| `screen-04-history-player.png` | Плеер движения роботов в прошлом: шкала времени, кнопки воспроизведения/паузы/перемотки, регулятор скорости, состояние склада на выбранный момент. |

Рекомендации:

- Формат — PNG (чёткая отрисовка интерфейса).
- Минимальная ширина — 1400 px (хорошее качество в печатной версии и при показе).
- Без альфа-канала и водяных знаков.
- Перед публикацией скрыть конфиденциальные данные конкретных заказчиков (имена пользователей, реальные ID объектов и т. п.) — например, через размытие или замену в любом редакторе.

После добавления файлов скриншоты появятся в документе при открытии его в любом
средстве просмотра Markdown (GitHub, VS Code, Typora) и при экспорте в PDF/DOCX через Pandoc.
